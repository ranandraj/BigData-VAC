# Final E-Commerce Project

Students should demonstrate:

1. Historical CSV/JSON -> NiFi -> HDFS.
2. PostgreSQL -> Debezium -> Kafka.
3. Python clickstream -> Kafka.
4. Kafka -> Flink.
5. Flink -> real-time metrics/anomalies -> MongoDB.
6. Historical/operational data -> Parquet-backed Iceberg tables.
7. Trino SQL for sales, customer, product and funnel analytics.
8. Streamlit dashboard.
9. Management report snapshot.
10. Airflow DAG for repeatable orchestration.

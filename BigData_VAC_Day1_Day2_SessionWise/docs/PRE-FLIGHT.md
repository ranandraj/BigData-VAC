# Pre-flight checker

Run `PRE-FLIGHT-CHECK.cmd` before installing the lab.

Checks Windows, 64-bit architecture, CPU, RAM, disk, virtualization, WSL, Virtual Machine Platform, Docker CLI/Compose/Engine, Winget, and all lab ports.

Recommended:
- 16 GB RAM: staged startup
- 32 GB RAM: complete stack
- 4+ logical CPU cores
- 80+ GB free disk
- hardware virtualization enabled

The checker is standalone and does not require the Big Data stack to be installed.
